# SudokuGame

## Vision

Create a build an interactive sudoku game web application with puzzle generator, solver, and unit tests. that delivers an exceptional user experience through modern technology and thoughtful design. SudokuGame aims to solve real user problems with a focus on reliability, performance, and usability.

## Tech Stack

- **Language:** C# / TypeScript
- **Framework:** Unity / WebGL
- **Rendering:** WebGL / OpenGL
- **State_Management:** Local Game Engine Loop
- **Database:** None (Local File / In-Memory)
- **Testing:** pytest
- **Deployment:** Standalone Executable / Local Python script
